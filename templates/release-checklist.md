# 发布清单模板

## 版本身份

- 应用名称 / 开发者主体：
- applicationId：
- versionName / versionCode：
- 源码标签 / 提交：
- 发布日期 / 渠道：
- 签名证书 SHA-256：
- 密钥备份核验人：

## 构建与测试

- [ ] JDK、Gradle、AGP、SDK 与依赖版本已记录。
- [ ] 单元测试与适用静态检查通过，正式包真机测试完成。
- [ ] 未连接开发电脑仍能使用，正式后端地址正确。
- [ ] 同签名覆盖更新保留数据，迁移已验证。
- [ ] 权限、原生库架构、16 KB 页大小等适用兼容要求已核验。
- [ ] 未包含私钥、服务商密钥、密码或测试个人信息。

## 对外材料

- [ ] 安装包签名核验通过。
- [ ] 文件名、大小、SHA-256 与更新说明正确。
- [ ] 下载链接由另一台设备实测。
- [ ] 名称、截图、描述、隐私政策、SDK 清单与产品一致。
- [ ] 适用的账号认证、APP 备案、版权与业务材料齐全。
- [ ] 市场适用测试和政策表单已完成。
- [ ] 反馈渠道、费用监控、备份和故障处理责任明确。

## 归档

- APK / AAB 保存位置：
- 下载链接与版本页面：
- Android Lint / 测试报告：
- mapping.txt（启用混淆时）：
- 已知问题：
- 修复 / 停止分发预案：
